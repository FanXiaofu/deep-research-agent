# Langfuse 和 LangSmith 在 LLM 可观测性上的差异研究报告

## 核心结论
1. LangSmith 在 API 生命周期管理方面更全面，包括 API 文档、测试、监控和安全，而 Langfuse 则侧重于实时监控和调试，提供详细的日志记录和性能监控功能。

3. LangSmith 在生产评估自动化规则、生产警报和托管部署方面更具优势，而 Langfuse 适合重视透明度和自定义的团队。
