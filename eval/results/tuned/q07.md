# LLM 推理中 KV Cache 的作用及其显存优化方法

## 核心结论
1. KV Cache 在 LLM 推理中通过缓存已计算的 Key 和 Value 向量，显著提升推理效率，将时间复杂度从 O(n²) 降低至 O(n)。
2. 优化 KV Cache 可以通过减少序列长度、注意力头个数、key_bits、动态稀疏化、KV Cache 量化、KV Cache 压缩、Prefix/Prompt Cache 复用等方法减少显存占用。
3. LMCache 是首个开源且应用最广泛的企业级 LLM 推理 KV Cache 层，通过高效的数据传输机制和模块化的连接器组件，支持跨引擎、跨请求共享 KV Cache。
4. 量化技术如 KV Cache 量化能够显著减少内存占用，同时保持模型性能。
5. Prefix/Prompt Cache 复用通过跨请求重用提示词片段的注意力状态，减少计算开销。

## 各维度发现

### 定义 KV Cache 及其在 LLM 推理中的作用
KV Cache 是大语言模型（LLM）推理中的关键优化技术，通过缓存已计算的 Key 和 Value 矩阵，避免重复计算，显著提升了推理效率。在自回归生成过程中，KV Cache 使模型能够高效利用历史信息，从而减少计算复杂度和显存占用。具体而言，KV Cache 通过在 Prefill 阶段缓存 Key/Value 状态，Decode 阶段直接复用历史缓存，将冗余的矩阵运算转化为高效内存读取，显著降低延迟与推理成本。例如，Llama-3 70B 模型在处理 64K token 时，约需 7.6GB 的 KV-cache。[4][5]

### 优化 KV 缓存机制以减少显存占用的方法与案例分析
优化 KV 缓存机制以减少显存占用的方法主要包括减少序列长度、减少注意力头个数、减少 key_bits、动态稀疏化、KV Cache 量化、KV Cache 压缩、Prefix/Prompt Cache 复用等。具体而言，减少序列长度和注意力头个数可以有效降低显存占用；动态稀疏化和 KV Cache 量化则通过减少冗余计算和降低存储精度来节省显存；KV Cache 压缩通过移除不必要 token 的 KV，对齐 KV 存储与 token 重要性，进一步减少显存占用。Prefix/Prompt Cache 复用则通过跨请求重用提示词片段的注意力状态，减少计算开销。这些方法共同作用，显著提升了大语言模型推理过程中的显存使用效率。[6][7][8][9]

### 现有优化策略对 KV 缓存性能影响的分析
现有研究指出，KV Cache 是大语言模型推理中关键的性能优化机制，但其也带来了显存占用过高的问题。研究发现，KV Cache 在处理长文本时容易导致显存爆炸，如 GPT-3 在处理 1024 长度序列时，典型配置下的 KV Cache 约占用 4.5GB 显存。为解决这一问题，Ollama 团队提出了 KV Cache 量化技术，通过降低 K/V 向量的数据精度，减少显存占用，同时保持模型性能。此外，Tri-shape 方法和 Prefix Cache 复用等策略也被提出，以优化 KV Cache 的使用，提高长上下文推理的可扩展性与经济性。[10][11][12]
