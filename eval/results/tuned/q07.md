# LLM 推理中的 KV Cache 及其显存优化方法

## 核心结论
1. KV Cache 在 LLM 推理过程中通过缓存已计算的 Key 和 Value 向量，显著提升了模型的推理速度，但同时增加了显存压力。
2. 通过减少序列长度、注意力头个数、key_bits、动态稀疏化、KV Cache 量化、KV Cache 压缩、Prefix/Prompt Cache 复用等方法，可以有效减少显存占用。
3. LMCache 是首个开源且应用最广泛的企业级 LLM 推理 KV Cache 层，通过高效的数据传输机制和模块化的连接器组件，支持跨引擎、跨请求共享 KV Cache。

## 各维度发现

### 定义 KV Cache 及其在 LLM 推理中的作用
KV Cache 是一种关键的优化技术，用于提升大型语言模型（LLMs）的推理效率。在 LLM 推理过程中，KV Cache 通过缓存已计算的 Key 和 Value 向量，避免重复计算，从而显著减少计算复杂度，提升推理速度。具体而言，KV Cache 在自回归生成过程中复用历史 token 的 Key 和 Value，将时间复杂度从 O(n²) 降低至 O(n)，实现线性扩展。这一机制类似于人类思维中的短期记忆系统，使模型能够高效利用历史信息。KV Cache 的应用不仅限于 LLMs，还扩展到了计算机视觉领域，如视频理解任务中的状态维护。尽管 KV Cache 带来了显著的速度提升，但也带来了显存压力，影响模型架构和推理框架设计。[1]

### 优化 KV 缓存机制以减少显存占用的方法与案例分析
1. **减少序列长度**：减少序列长度可以有效降低显存占用。[6]
2. **减少注意力头个数**：减少注意力头个数可以有效降低显存占用。[6]
3. **减少 key_bits**：通过降低存储精度来节省显存。[8]
4. **动态稀疏化**：通过减少冗余计算来节省显存。[6]
5. **KV Cache 量化**：通过降低存储精度来节省显存。[8]
6. **KV Cache 压缩**：通过移除不必要 token 的 KV，对齐 KV 存储与 token 重要性，进一步减少显存占用。[6]
7. **Prefix/Prompt Cache 复用**：通过跨请求重用提示词片段的注意力状态，减少计算开销。[6]
