# Tavily、Serper、Bing Search API 优劣对比研究报告

## 核心结论
1. Tavily专为AI代理设计，性能较好，但国内访问偶有波动，价格较高。
2. Serper功能全面，支持多种搜索类型，但需要API Key，价格较低。
3. Bing Search API已退役，推荐使用替代方案如Tavily。

## 各维度发现

### 性能对比
- **Tavily**：专为AI代理设计，与LangChain和LlamaIndex集成良好，延迟较低，中文搜索质量表现较好 [1][5]。
- **Serper**：支持多种搜索类型，但国内访问需API Key，价格较高 [1][2][3]。
- **Bing Search API**：已退役，不再提供服务 [4][6]。

### 安全性、功能、成本、易用性对比
- **Tavily**：专为AI代理设计，支持自然语言搜索和结构化结果，但国内访问偶有波动，价格相对较高 [1][5]。
- **Serper**：功能全面，支持多种搜索类型，但需要API Key，价格较低 [1][2][3]。
- **Bing Search API**：已退役，不再提供服务，推荐使用替代方案如Tavily [4][6]。

### 文档支持
- **Tavily**：文档支持良好，与LangChain和LlamaIndex集成文档详细 [1][5]。
- **Serper**：文档支持良好，功能介绍详细 [1][2][3]。
- **Bing Search API**：已退役，不再提供服务 [4][6]。

### 不确定性与来源冲突
- **Bing Search API**：已退役，不再提供服务，但部分研究笔记提及仍在使用，需进一步确认 [4][6][7]。

## 不确定性与来源冲突
- **Bing Search API**：部分笔记提及仍在使用，但官方已宣布退役，需进一步确认具体使用情况和替代方案的可行性。
